# 整句字帖

任务：把输入的一整句话放到绘画窗口旁，连续临摹；只在遇到不熟悉的字时查看笔顺。

主界面是字帖，不是单字查询面板。沿用 Rizum Glass 的灰阶、字体角色、细描边和克制的反馈，不沿用参考应用的信息结构。默认只显示霞鹜文楷，按字帖的行数决定窗口高度；字体、字号、编辑和穿透保留在一条工具栏。设置中的双字体开启后，同一个字上下对齐，适合比较字形。

输入一次整句话，点击完成或回车即可收起输入栏；无需逐字打开。保留标点与顺序，支持最多 512 个字符；超出可见高度时，只滚动字帖，操作栏保持可见。点击字会在字帖下展开笔顺；左右方向键换字，空格播放/暂停，Esc 收起。输入框中的左右方向键仍用于编辑。

删除：RIZUM 副标、会读的字也能慢慢写出来、留在创作里、常驻系统状态说明、双大卡片、编辑态重复的编辑按钮、设置页重复返回按钮。保留唯一的空态操作说明“整句显示，点字看笔顺”。错误与快捷键说明仅出现在需要它们的状态。

尺寸：窗口宽 560 逻辑像素；默认 64 字号时每行最多 7 字，避免闭合标点出现在行首。单行收起输入栏后高 174，两行高 246。笔顺展开增加 176。字帖视口按完整行计算，默认最多 4 行，展开笔顺时最多 2 行；双字体时按成对的行计算。留白放在滚动区外，防止露出下一行的半个字。超出部分内部滚动，操作栏始终完整。Win32 客户区尺寸按 DPI 向上取整；拖动使用鼠标捕获和位移，松开即停止。

动效证据：

- `v2-entry-start/middle/end.png`：首次字帖内容在 240ms 内淡入并回到原位。
- `v2-press-start/middle/end.png`：按钮 80ms 按压位移和透明度反馈，释放执行编辑动作。
- `v2-detail-start/middle/end.png`：笔顺区 220ms 展开，原句和选中位置保留。

遵循系统减少动态效果设置，停止装饰过渡；笔顺仍可逐笔查看。

检查不能假定独占用户桌面。检查入口关闭系统助手，禁用窗口激活和拖动；窗口从隐藏状态开始，设置为不激活的工具窗口并移动到虚拟桌面边界之外，随后才允许 GPU 渲染。位置检查失败就隐藏并报错。没有向 Windows 发送按键或鼠标事件。官方 TestGpuixRenderer 在此 Windows 环境会创建可见窗口，已弃用。

首轮独立评审 7/10：笔顺区过高、细小控件对比不足、编辑态与设置页重复操作。已改成横向笔顺区，提高可用图标对比，播放和步进采用 36px 点击区域，并删去重复动作。后续评审与验证结论见验收记录。

真实中文输入法候选提交、CSP/KalaPaint 的自动唤起和实际鼠标拖动，仍需在用户允许的空闲操作时段验收；渲染器内部事件不能替代这些验证。
