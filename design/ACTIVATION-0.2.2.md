# 0.2.2：双击右 Ctrl 唤起

用户用键盘和中文输入法输入要临摹的文字；唤起不应要求先移动笔去点击，也不能固定占用绘画软件的组合键。采用用户选定的双击右 Ctrl，删除原来的三组全局组合键和备用键。保留切换中文时自动唤起的独立开关。

设置只增加一个可关闭的「双击右 Ctrl 唤起」，删掉两行只读的旧快捷键说明。隐藏与穿透共用这个恢复入口，关闭手势时禁用这两个按钮。恢复穿透或未完成输入时保留文字；从已完成字帖开始下一句时先记入最近输入。未改动其他页面的视觉、字体和动效。

## 实现边界

- Rust `activation.rs` 创建不可见的 message-only window，注册键盘和鼠标的 `RIDEV_INPUTSINK | RIDEV_DEVNOTIFY`，不使用 `RIDEV_NOLEGACY`、`RIDEV_NOHOTKEYS` 或键盘钩子。按键仍交给前台应用。
- 只用右 Ctrl 的按下、松开时间辨认手势。其他键不作文本转换、不保留序列、不输出日志，只取消待识别手势。当前是否有键或鼠标按钮按住，仅在右 Ctrl 变化时查询。
- 每次轻点最多 250 ms，两次间隔最多 400 ms；触发后 650 ms 内忽略重复手势。同一键盘、同一前台窗口内完成；字伴自身作为前台时不触发。
- 单击、长按、自动重复、夹杂普通键、Ctrl 组合键、鼠标按钮/滚轮、已有按键按住、换窗口或键盘均不构成双击。只有移动鼠标不会取消。
- 开关保存后由消息线程注册/注销；失败显示可恢复的状态。不覆盖历史偏好，旧配置未包含 `doubleCtrl` 时默认开启。

系统接口依据：[Microsoft Raw Input overview](https://learn.microsoft.com/en-us/windows/win32/inputdev/about-raw-input) 与 [RegisterRawInputDevices](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-registerrawinputdevices)。这些接口提供被动输入消息；它们不能保证其他软件没有给“双击 Ctrl”分配自己的动作。

## 验证

- 14 组人工输入时序回放通过：正常两次轻点、单次、长按、自动重复、间隔超时、键盘/鼠标打断、预先按住其他键、两次间夹杂输入、前台切换、键盘切换、禁用/断连、快速四次、稍后再次触发、32 位消息时间回绕。
- 用同一 Listener 代码执行短暂注册检查：键盘与鼠标注册成功，目标窗口不可见，无普通输入拦截标志；禁用、重新启用和销毁后注册全部清理，前台窗口不变。检查未消费真实输入消息。
- 编译后的隔离原生窗口连续 3 轮各 11 项检查通过：开关、无恢复入口时禁用隐藏/穿透、重新启用、穿透恢复、参考文字和草稿保留、已完成句子进入历史、隐藏恢复、恢复后的设置操作。
- 已查看真实原生设置页截图，标签与说明没有裁切。沿用现有开关动效，不添加无关动画。
- 无真实桌面输入注入、前台接管或输入法切换。CSP/KalaPaint/数位笔环境下的真实双击与输入法焦点交接仍待用户实际使用确认；隔离回放不代替这项验收。
