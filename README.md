# 字伴

Windows 悬浮汉字字帖。输入整句话，放在画布旁连续临摹；点字查看离线笔顺。

0.2.3 新增默认关闭的「开机自启」。开启后登录 Windows 时在后台启动，双击右 Ctrl 再输入文字；无需每次手动打开软件。

![整句字帖](design/v2-sentence.png)

## 使用

从 Releases 下载 Windows 便携包，完整解压，双击 `Ziban.exe`。无需安装 Node、Rust 或字体。请保留整个文件夹。更新前先退出旧版。

- 输入一句话，点击「完成」或回车。输入栏收起，整句话按行显示；较长内容可滚动。
- 点工具栏「编辑」继续改文字；字体和字号随时可调。
- 点任意汉字展开笔顺。`←` / `→` 换字，空格播放或暂停，`Esc` 收起。输入框中的方向键仍用于编辑。
- 在设置中开启双字体对照、米字格或深色外观。双字体按同一字符上下对齐。
- 拖动顶部「字伴」旁的空白区域移动窗口。图钉切换置顶，减号隐藏，叉号退出。
- 鼠标穿透后可直接在下方画布画画；双击右 Ctrl 恢复操作。
- 在设置中开启「开机自启」后，下次登录 Windows 会在后台运行。默认不显示窗口、不抢焦点；平时手动打开仍正常显示。可以随时在设置中关闭。

最多显示 512 个字符，保留标点和顺序。内置思源宋体、霞鹜文楷及 9,574 个汉字的离线笔顺，也能选择本机字体。笔顺采用数据源的楷书顺序，不随临摹字体变为行草笔顺。

## 唤起和输入法

在其他应用中，**单独轻点两下右 Ctrl**，然后正常用输入法打字。每次按下不超过 250 毫秒，两次之间不超过 400 毫秒。长按、左 Ctrl、配合其他按键或鼠标按钮的操作不算双击。两次轻点须来自同一键盘，期间不切换前台窗口。

隐藏和鼠标穿透后也用双击右 Ctrl 唤回。正在编辑的文字不会清空；从穿透状态恢复时保留参考文字。已完成的句子先进入最近输入，再开始新句子。在字伴自身窗口中不响应这个全局手势。

设置中可关闭「双击右 Ctrl 唤起」。关闭后隐藏和鼠标穿透按钮同时禁用，避免失去恢复入口；仍可点击输入框，或重新双击 EXE 找回窗口。0.2.2 不再注册旧版 Ctrl + Alt + 空格、J、H、P 及其备用组合。如果其他软件也使用双击 Ctrl，请在其中一个软件关闭该手势。

自动唤起观察同一前台窗口内从非中文切到中文的变化，并通过 Windows 辅助功能判断焦点是否在文本控件中；未知控件不接管。已经是中文模式时可双击右 Ctrl。输入时字伴需要短暂获得焦点，完成后交回此前窗口。回车选定候选字通常只完成候选提交，再按一次才完成输入。

**已验证手势时序回放、被动输入注册与清理，以及隔离原生窗口内的设置、隐藏和穿透恢复。真实键盘在 CSP/KalaPaint 中的双击唤起、输入法候选提交、自动唤起以及实际鼠标拖动尚未完成本版桌面验收。** 自绘画布、管理员窗口、远程桌面和不同输入法可能影响行为。

## 数据

本机保存最后一句、最近 18 条输入及偏好：`%LOCALAPPDATA%\Rizum\Ziban\preferences.json`。最近输入可清空。不读取其他应用的文本内容，不记录全局按键。没有账号、云同步或 Windows 后台服务；退出即停止监听。

开机自启默认关闭，只有主动切换开关才写入当前用户的 Windows Run 项 `Rizum.Ziban`，不需要管理员权限。开关读回该安装的自启命令，普通偏好保存和软件更新不会重新开启它。路径有空格或中文时会正确加引号。便携目录移动后，需要在新位置重新开启；删除软件前可先关闭。Windows 的启动应用管理仍可以阻止或延迟自启。

## 技术栈

SolidJS 1.9.15 + TypeScript + 官方 `@gpuix/solid` / `@gpuix/native` **0.10.0**，Bun 1.3.14 打包；Rust 负责 Windows 输入模式、唤起手势、焦点和偏好存储。没有 React、浏览器或 WebView。手势使用 Raw Input 消息，只保留右 Ctrl 的时序和是否被其他操作打断，不翻译文本、不保存按键序列、不安装键盘钩子、不吞键。

视觉变量及部分 Windows 适配参考 VRC Bili Relay 的 Rizum Glass（Apache-2.0）。该参考项目使用本地 `0.7.0-rizum.1` 分支；字伴使用 npm 官方 0.10.0，未修改参考项目。新旧包不能混用。

```powershell
bun install --frozen-lockfile
bun tools/prepare-strokes.ts
cargo build --release
bun run typecheck
bun run dev
bun run build
python tools/package-delivery.py
```

构建结果位于 `dist/`，需完整分发，包含原生 `.node` 库、Rust 辅助程序和资源。可选的 Python 3 打包脚本在 `release/` 生成便携 ZIP 和 SHA-256 校验值。内置字体用原始轮廓绘制字帖，避免系统回退成另一字体。

开发检查端点仅在 `ZIBAN_INSPECT=1` 时启用，正式构建固定关闭。不要在用户正常使用电脑时抢焦点、切换输入法或注入系统按键。验证使用类型检查、构建、原生截图与应用内部事件，不运行功能测试套件。
